# Power BI - Retail

Aca va el reporte de Power BI que crearas en **tu PC personal** con Power BI
Desktop (gratis, sin cuenta):

1. Obtener datos -> Texto/CSV -> `../data/transacciones.csv`.
2. Ideas de visuales:
   - Matriz de afinidad (producto A vs producto B, color por lift).
   - Top oportunidades por lift (barras).
   - Ventas por categoria (treemap o dona).
   - Ticket promedio por tienda.
3. Guarda `retail.pbix` en esta carpeta + 2-3 capturas (PNG).

> NO uses tu cuenta/tenant de Walmart. Power BI Desktop no requiere cuenta.
