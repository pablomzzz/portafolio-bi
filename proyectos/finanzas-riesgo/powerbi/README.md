# Power BI - Finanzas

Reporte de Power BI a crear en **tu PC personal** con Power BI Desktop:

1. Obtener datos → Texto/CSV → `../data/estados_financieros.csv`.
2. Crea medidas DAX para los ratios (margen, liquidez, endeudamiento, ROE).
3. Ideas de visuales:
   - Ranking de score de riesgo (barras con color por nivel).
   - Scatter liquidez vs endeudamiento (tamaño = ingresos).
   - Tendencia de ingresos y margen por empresa.
   - Mapa de calor de riesgo por sector.
4. Guarda `finanzas.pbix` en esta carpeta + capturas (PNG).

> NO uses tu cuenta/tenant de Walmart. Power BI Desktop no requiere cuenta.
